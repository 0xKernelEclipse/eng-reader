# قارئ الكلمات الإنجليزية — اختبار التوافق

هذا المستودع يبدأ بالمرحلة الصحيحة للمشروع: اختبار متوافق مع iPhone 7 Plus / iOS 15.8.8 قبل بناء قارئ المفردات الكامل. لا يرفع الصورة أو النص إلى أي خادم. بعد إعداد الملفات محليًا، يعمل OCR من ملفات محلية مخزنة في PWA.

## مخاطر التوافق التي يجب اختبارها على الهاتف

- قراءة الصور تعتمد على WebAssembly وWeb Worker في Safari القديم نسبيًا؛ لهذا ثُبّت `tesseract.js` على `5.1.1` بدل التحديث التلقائي.
- محرك OCR ونموذج الإنجليزية يُحضّران محليًا في `public/ocr/`، ولا توجد تبعية CDN وقت التشغيل.
- Safari قد يعرض صوتًا عربيًا لا يكون محليًا. صفحة الاختبار تعرض اسم الصوت وهل يبلّغ النظام أنه محلي؛ لا يمكن للويب أن يضمن نطقًا عربيًا دون إنترنت قبل اختبار الهاتف فعليًا.
- Service Worker يحتاج HTTP(S)، وليس `file://`. أضيفي التطبيق من Safari بعد نشر HTTPS.

## تشغيله في Windows 10

PowerShell قد يمنع `npm.ps1`، لذلك استخدمي `npm.cmd`:

```powershell
npm.cmd install
npm.cmd run prepare-ocr
npm.cmd run dev
```

افتحي العنوان الذي يعرضه Vite. للاختبار على هاتف آخر في الشبكة أضيفي عنوان IP الخاص بالكمبيوتر بدل `localhost`، لكن يجب استخدام HTTPS عند اختبار التثبيت وService Worker بصورة موثوقة. أسهل مسار هو نشر build على GitHub Pages أو أي استضافة static HTTPS.

## بناء ونشر نسخة الاختبار

```powershell
npm.cmd run build
npm.cmd run preview
```

الناتج في `dist/`. انشري محتويات `dist/` على static host عبر HTTPS. لا تنشري `node_modules/` أو ملفات المصدر.

## اختبار iPhone 7 Plus

1. افتحي الموقع عبر Safari مع الإنترنت واتركيه مفتوحًا حتى تصبح حالة الملفات «جاهز للعمل دون إنترنت».
2. من Share اختاري **Add to Home Screen** ثم افتحيه من الأيقونة.
3. اختبري زر الكاميرا، صورة صفحة واضحة، OCR، اختبار الإنجليزية، واختبار العربية.
4. أغلقي التطبيق، أوقفي Wi‑Fi والبيانات، ثم افتحيه من الشاشة الرئيسية واختبري الصورة وOCR مرة أخرى.
5. سجّلي إن كان الصوت العربي يحمل «محلي» أو «قد يحتاج إنترنت»، وما إذا كان ما زال يعمل عند قطع الاتصال.

## ما الذي لا يبنيه هذا الاختبار بعد

لا توجد بعد قائمة مفردات أو قاموس إنجليزي-عربي أو تسلسل تكرار الكلمات. هذه خطوة مقصودة: نتيجة اختبار OCR والصوت دون إنترنت على الهاتف هي بوابة بناء MVP، وليست شيئًا يمكن تأكيده من Windows.

## تحديث إصدار OCR

الإصدار مثبت في `package.json`. بعد تغييره، نفّذي `npm.cmd install` ثم `npm.cmd run prepare-ocr` واختبري الهاتف من جديد. لا تستخدمي نطاقًا مثل `^` لإصدار OCR.
