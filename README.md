# قارئ الكلمات الإنجليزية — English Vocabulary Reader PWA

تطبيق ويب تقدمي (PWA) مخصص وسهل للغاية لمساعدة الأمهات والطلاب على تعلم وقراءة مفردات الكتب والصفحات المدرسية الإنجليزية دون الحاجة لكتابة أي كلمة يدويًا وبدون إنترنت.

**المستودع:** [https://github.com/0xKernelEclipse/eng-reader](https://github.com/0xKernelEclipse/eng-reader)

---

## كيف يعمل التطبيق؟ (تجربة المستخدم الأساسية)

1. **التقاط الصورة:** تضغط الأم على زر **«📷 صوّري الصفحة»** أو تختار صورة من المعرض، أو تضغط **«📄 صفحة تدريبية»** للتجربة الفورية.
2. **التعرف على النص (OCR):** يقرأ محرك Tesseract المدمج محليًا بالكامل النص الإنجليزي من الصورة داخل الهاتف دون إرسال أي صورة إلى الإنترنت.
3. **استخراج الكلمات والترجمة:** يُنظف التطبيق الكلمات، ويحذف التكرار مع الحفاظ على ترتيب الصفحة، ويطابق كل كلمة مع قاموس محلي إنجليزي-عربي فوري.
4. **الاستماع والتكرار التلقائي:** تضغط الأم على **«▶ ابدأ القراءة»**، فينطق الهاتف تلقائيًا:
   - الكلمة الإنجليزية (تكرار 1)
   - الكلمة الإنجليزية (تكرار 2)
   - الكلمة الإنجليزية (تكرار 3)
   - المعنى بالعربية (مرة واحدة)
   - ثم ينتقل مباشرة إلى الكلمة التالية!

## الأجهزة المدعومة

1. **iPhone (الأولوية الأولى):**
   - متوافق خصيصًا مع **iPhone 7 Plus** ونظام **iOS 15.8.8** ومتصفح Safari.
   - يدعم التثبيت كـ Web App عبر زر **Add to Home Screen**.
   - أيقونات PNG مخصصة (192×192 و 512×512) لظهور أيقونة التطبيق على شاشة الآيفون.
   - تجنب مشاكل الذاكرة لمتصفح Safari القديم عبر ضغط وتحسين دقة الصور وتفريغ الذاكرة فورًا.
2. **Android:**
   - متوافق مع Chrome والمتصفحات الحديثة وتثبيت PWA مباشر.
3. **Windows / Mac:**
   - يعمل على Chrome و Edge و Safari دون أي أدوات خارجية.

## مميزات التصميم والتطبيق

- **تصميم عربي أنيق وداكن أولاً (Dark-First Premium Design):** راحة للعين مع إمكانية التبديل للمظهر الفاتح.
- **أزرار عملاقة وواضحة:** ارتفاع الأزرار 64-72px لتسهيل اللمس لغير التقنيين وكبار السن.
- **بدون رموز تعبيرية (No Emojis):** استخدام أيقونات SVG نقية وعالية الدقة فقط.
- **تحكم صوتي متكامل:** إيقاف مؤقت، استئناف، إعادة الكلمة، الانتقال للكلمة السابقة والتالية.
- **تحكم في السرعة والتكرار:** سرعات من 0.6x حتى 1.15x، وتكرار 3 أو 4 أو 5 مرات.
- **وضع استخراج المفردات:** اختيار كلمات الدروس المهمة (فلترة كلمات الوصل) أو استخراج كل الكلمات.
- **لوحة فحص الجهاز والتوافق:** فحص توافر Service Worker، التخزين المحلي، وحالة الأصوات الإنجليزية والعربية وهل هي محلية دون اتصال.

## التشغيل والتطوير على Windows 10

PowerShell قد يمنع تشغيل `.ps1`، لذلك استخدم دائمًا `npm.cmd`:

```powershell
# 1. تثبيت الحزم
npm.cmd install

# 2. تجهيز ملفات OCR والأيقونات محليًا
npm.cmd run gen-icons
npm.cmd run prepare-ocr

# 3. تشغيل سيرفر التطوير المحلي
npm.cmd run dev
```

---

## بناء ونشر المشروع (Production Build)

```powershell
npm.cmd run build
```

يقوم هذا الأمر تلقائيًا بـ:
1. توليد أيقونات PWA ذات الخلفية الداكنة وشعار الكتاب.
2. تجهيز ملفات Tesseract WebAssembly ونموذج الإنجليزية محليًا في `dist/ocr/`.
3. فحص الـ TypeScript وخلوه من أي أخطاء (`tsc --noEmit`).
4. بناء الحزم عبر Vite وضغط الأصول (حجم كود التطبيق فقط 18 KB مضغوط!).
5. بناء `dist/service-worker.js` لتخزين كافة الملفات (23 ملف محلي) للعمل دون إنترنت.

## النشر على Vercel بضغطة واحدة

المشروع مُجهز بالكامل بملف `vercel.json` الذي يضبط ترويسات `Content-Type: application/wasm` و `application/gzip` وترويسات الـ Service Worker:

1. ادخل على [Vercel](https://vercel.com) وسجّل دخولك بحساب GitHub.
2. اضغط **Add New Project** واختر مستودع `0xKernelEclipse/eng-reader`.
3. سيتعرف Vercel تلقائيًا على Vite وإعدادات البناء.
4. اختر اسم المشروع (مثل: `eng-reader` ليصبح الرابط `eng-reader.vercel.app`).
5. اضغط **Deploy**!

## طريقة التثبيت والاستخدام على iPhone 7 Plus

1. افتحي الرابط المنشور على Vercel داخل متصفح **Safari** وأنتِ متصلة بالإنترنت.
2. انتظري حتى تظهر حالة الملفات في الأسفل **«جاهز للعمل دون إنترنت»**.
3. من شريط Safari بالأسفل، اضغطي على زر المشاركة **Share** (مربع به سهم للأعلى).
4. مرري لأسفل واختاري **«إضافة إلى الشاشة الرئيسية» (Add to Home Screen)**.
5. أغلقي Safari، وافتحي التطبيق من أيقونة **«قارئ الإنجليزية»** التي ظهرت على شاشة هاتفك.
6. يمكنكِ الآن إيقاف الـ Wi-Fi والبيانات وتجربة التقاط الصور والاستماع!

## ملاحظة هامة حول الأصوات على iOS

- محرك التعرف على النص (OCR) والقاموس الإنجليزي-العربي يعملان **100% دون إنترنت** ومخزنان بالكامل على هاتفك.
- نطق الأصوات يعتمد على محرك Web Speech الخاص بنظام iOS. تقوم لوحة الفحص بإعلامكِ إذا كان الصوت العربي المثبت على الهاتف محليًا (Local) أو قد يحتاج اتصالاً وفقًا لإصدار iOS لديك.
